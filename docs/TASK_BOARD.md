# 任务看板

本文档记录“麻吉桌宠”的任务拆分和当前优先级。状态只表达项目管理状态，不替代 Git 提交。

## 状态说明

- `待规划`：方向存在，但范围还没定。
- `待做`：范围清楚，可以进入实现。
- `进行中`：正在当前或某个 Codex 对话中处理。
- `待验证`：代码或文档已完成，需要测试确认。
- `完成`：已验证并沉淀到文档/Git。
- `暂缓`：先不做，未来重新评估。
